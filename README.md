# My Git Finds

Interesting repos I've come across — not my own projects, just things worth bookmarking.

## Smart Home

- [wroblisko/hasscontrol](https://github.com/wroblisko/hasscontrol) — A ConnectIQ widget that controls Home Assistant scenes, lights, switches, and more directly from a Garmin watch, relayed through a paired phone.

## AI / Media

- [debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio) — Open-source, fully-local ElevenLabs alternative: voice cloning, voice design, video dubbing, dictation, transcription, and audiobook creation in 646 languages. Electron app plus a local API/MCP server for agents (default engine k2-fsa/OmniVoice).

## macOS / Productivity

- [vorssaint/vorssaint-utils](https://github.com/vorssaint/vorssaint-utils) — Free, open-source, local-first macOS menu bar toolkit that replaces a dozen paid Mac apps with one icon: per-app volume (boost past 100%), system monitor, better app switcher, window snapping, Dock previews, clipboard history, text snippets, file shelf, uninstaller. Install only the modules you use; no account, telemetry, or subscription.

## AI / Dev-Tools (agents / Claude Code)

- [headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom) — Compresses tool outputs, logs, files, and RAG chunks locally before they reach the LLM (≈20% fewer tokens for coding agents, 60–95% for JSON), same answers. Ships as a Python library/CLI, a drop-in proxy, an MCP server, and an agent-wrap for Claude Code, Codex, Cursor and others. Compression runs on your machine — nothing is uploaded.
- [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) — Persistent memory across sessions: captures what an agent does, compresses it with AI, and injects relevant context into future sessions. Works with Claude Code and many other agents; hosted memory by default with an opt-in local provider.
- [anthropics/claude-plugins-official — claude-code-setup](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/claude-code-setup) — Official Anthropic read-only skill that scans a codebase and recommends tailored Claude Code automations (MCP servers, skills, hooks, subagents, slash commands).
- [diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute) — MIT AI gateway: one OpenAI-compatible endpoint over 359 providers / 1200+ models (Claude, GPT, Gemini, Kimi, GLM, DeepSeek, MiniMax), with free-tier aggregation, quota-aware auto-fallback, token compression, MCP/A2A, and a desktop/PWA. Works with Claude Code, Codex, Cursor, OpenCode, Cline, Copilot.
- [Jakeschincariol/instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill) — Thirteen Claude skills that run an Instagram account (reels from 26 scored hook formulas, viral research, caption linter, humanizer, weekly planner). MIT, no signup or API key; the skills draft, you post.

## Lists & Collections

- [zenteek-radio-stations.md](./zenteek-radio-stations.md) — Curated internet-radio stream URLs for the [Zenteek](https://zenteek.app/) player, grouped by sound and quality (lossless FLAC first, then SomaFM lounge/chill, Radio France, and other French stations).
